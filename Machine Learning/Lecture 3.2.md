# Multilayer Perceptron (MLP)

Forward Pass
The network processes an input through successive layers. Each neuron computes a weighted sum of its inputs, adds a bias, and applies a nonlinear activation function.

Cost Function
A cost (or loss) function is defined to quantify how far the network’s predictions are from the true values.

Backpropagation – The Backward Pass
To minimize the cost, the algorithm computes gradients of the cost with respect to each weight and bias.

Weight Updates
With the computed gradients, the network’s weights and biases are updated.

Popular Activation Functions
- ReLU: Rectified Linear Unit
	- Computational efficiency
- Sigmoid
	- Useful for in binary classification
- Tanh
	- Symmetrical around the origin
