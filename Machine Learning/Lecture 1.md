# Introduction to Pattern Recognition and Machine Learning

> Pattern Recognition
> an automated recognition of patterns in data

> Machine Learning
> a field of study that gives the computer the ability to learn without being programmed, explicitly.

Machine Learning Taxonomy:
- Supervised Learning
- Unsupervised Learning
- Reinforcement Learning

### Supervised Learning

- Dataset contains labels
- **Regression** is a continuous variable. While **Classification** is a discrete variable

Supervised learning in Computer Vision:
- Image classification
- Object localization and detection

Supervised learning in Language Processing:
- Machine translation

### Unsupervised Learning

- Dataset contains no labels
- Clustering
