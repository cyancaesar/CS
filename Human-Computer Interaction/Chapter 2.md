# Usability Principles

## Levels of Consideration

1. Meta-display level
2. Display Layout
3. Element level

## UI Design Principles

- Learnability
- Flexibility
- Robustness


### Learnability Principles

- Predictability
- Synthesizability
- Familiarity
- Generalizability
- Consistency

### Flexibility Principles

- Dialog Initiative
- Multithreading
- Task migratability
- Substitutivity
- Customizability

### Robustness Principles

- Observability
- Recoverability
- Responsiveness
- Task Conformance
