### Cognitive Processing

- Selective Attention
- Learning

**Learning**

- Procedural Learning
	- How to do something
- Declarative Learning
	- Facts about something

Facilitated by:

- By analogy
- By structure & organization
- If presented in incremental units
- Repetition

**Problem Solving**

- Reasoning
	- Deductive
		- If A, then B
	- Inductive
		- Generalization from previous cases to learn about new ones
	- Abductive
		- Reasoning from a fact back to the action or state that caused it
