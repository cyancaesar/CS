Objectives:
- Get insight into the operational processes of data communications.
- Specify the main functional elements of a data communication system.
- Modes of data transmission as well as direction of data flow.

1. Information Source
	1. Message produced by the information source may not be electrical.
	2. Input transducer converts the message to a time-varying electrical quantity called message signal.
2. The Transmitter
	1. Data generated by a source can not transmitted directly.
	2. Transmitter transforms information to EM signals that can be transmitted across the transmission system.
	3. Signal processing operation performed by the transmitter include amplification, filtering, and modulation.
3. The Communication Channel
	1. Channel Provides the electrical connection.
	2. Wired or wireless
4. The Receiver
	1. Extracts the input signal from the degraded version
	2. Performs demodulation and other operations.

Communications Systems
- Analog
- Digital

Analog Communication System:
- To transmit data using analog modulation.
- The AM, FM and TV transmissions.

Digital Communication System:
- To transmit digital data using digital or analog modulation.
- Data might be binary or binary coded of analog data.

Criteria for Communication Systems
1. Data delivery
2. Data integrity
3. Timeliness of data transfer

Why Digital?
1. Use of modern digital technology
2. Data integrity
3. Ease of multiplexing and robust transmission
4. Security and privacy
5. Integration of diverse services
6. Performance monitorability

Elements of digital communication system
1. Information source
2. Source encoder/decoder
3. Channel encoder/decoder
4. Modulator/demodulator

Why modulation?
1. Overcoming some equipment limitations
2. Removing interference
3. Reducing noise
4. Allowing efficient capacity utilization
5. Matching signal to channel

Line configuration: a way through which two or more communicating devices attach to the transmission line.

Categories of line configuration
- Point-to-point
- Multipoint (multidrop)

Direction of data flow: two linked devices can communicate with each other by sending and receiving data.

Categories of direction of data flow
- Simplex
- Half-duplex
- Full-duplex

Transmission modes: of a binary data across a link can be accomplished in either parallel or serial mode.

- Parallel
- Serial
	- Synchronous
	- Asynchronous

Asynchronous
- Timing is unimportant
