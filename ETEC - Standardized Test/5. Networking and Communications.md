# SKU 5.1

**Introduction to Networking and Communications**

Topics:

1. Organization of the Internet.
2. Network terminology.
3. Layers of network architecture.
4. Network complexity (edges, core, etc.).
5. Names and addresses in a network.
6. Basics of naming schemes and resource location.
7. Client-server socket-based application implementation.
8. Local Area Network.
9. Wireless Networks and Mobility.

SLOs:

5.1.1: Describe the organization of the Internet.
5.1.2: Define network terminology.
5.1.3: Describe the layers of network architecture.
5.1.4: Identify the various network complexity (edges, core, etc.).
5.1.5: Compare names and addresses in a network.
5.1.6: Define the basics of naming schemes and resource location.
5.1.7: Implement a simple client-server socket-based application.
5.1.8: Compare and contrast IP with Ethernet.
5.1.9: Describe the wireless network organization.
5.1.10: Describe how wireless networks enable mobility.
