# SKU 4.1

**Database Systems and Data Modeling**

Topics:

1. Components of database systems.
2. Designs for core database system components.
3. Components of a database system.
4. DBMS functions and their role in a database system.
5. Declarative query languages.
6. Data models comparison, including internal structures.
7. Principles of modeling notation and their usage (e.g., Entity-Relation Diagrams or UML).
8. Basics of the relational data model.
9. Modeling concepts of the relational data model.
10. Main concepts of the Object-Oriented model.

SLOs:

4.1.1: Describe the Components of database systems.
4.1.2: Discuss designs for core database system components such as query optimizer, query executor, storage manager, access methods, and transaction processor.
4.1.3: Explain the components of a database system and give examples of their use.
4.1.4: Identify major DBMS functions and describe their role in a database system.
4.1.5: Use a declarative query language to elicit information from a database.
 4.1.6: Compare data models, including internal structures, for different types of data.
4.1.7: Describe principles of modeling notation and their usage (e.g., Entity-Relation Diagrams or UML)
4.1.8: Describe the basics of the relational data model.
4.1.9: Apply the modeling concepts of the relational data model.
4.1.10: Describe the main concepts of the Object-Oriented model.
