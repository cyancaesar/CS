# SKU 8.1

**Algorithms, Design, and Development Methods**

Topics:

1. Concept of algorithms for solving simple problems.
2. Implementation, testing, and debugging algorithms for solving simple problems.
3. Implementation, testing, and debugging of simple recursive functions and procedures.
4. Implementation of divide-and-conquer algorithm for solving a problem.
5. Techniques of decomposition and abstraction.
6. Coding errors (e.g., buffer overflows, memory leaks, malicious code) and strategies for avoiding such errors.
7. Strategies used for testing and debugging simple programs.
8. Modern IDEs.
9. Standard libraries of a programming language.
10. Documentation and program style guidelines that improve the readability and maintainability of software.

SLOs:

8.1.1: Create algorithms for solving simple problems.
8.1.2: Use a programming language to implement, test, and debug algorithms for solving simple problems.
8.1.3: Implement, test, and debug simple recursive functions and procedures.
8.1.4: Implement a divide-and-conquer algorithm for solving a problem.
8.1.5: Apply the techniques of decomposition and abstraction.
8.1.6: Trace the execution of various code segments and summarize their computations.
8.1.7: Identify coding errors (e.g., buffer overflows, memory leaks, malicious code) and apply strategies for avoiding such errors.
8.1.8: Apply a variety of strategies to the testing and debugging of simple programs.
8.1.9: Construct, execute and debug programs using a modern IDE.
8.1.10: Construct and debug programs using the standard libraries of a programming language.

# SKU 8.2

**Fundamental Programming Concepts and Data Structures**

Topics:

1. Primitive data types, standard conditional and iterative control structures and functions.
2. Usage of each of the following fundamental programming constructs: basic computation, simple I/O, file I/O, standard conditional and iterative structures, the definition of functions, and parameter passing.
3. Concept of recursion and give examples of its use.
4. Usage each of the following data structures: arrays, records, strings, linked lists, stacks, queues, sets, and maps.
5. Performance of alternative implementations of data structures.
6. Dynamic and static data structure implementations.

SLOs:

8.2.1: Write programs that use primitive data types, standard conditional and iterative control structures and functions.
8.2.2: Design, implement, test, and debug a program that uses each of the following fundamental programming constructs: basic computation, simple I/O, file I/O, standard conditional and iterative structures, the definition of functions, and parameter passing.
8.2.3: Describe the concept of recursion and give examples of its use.
8.2.4: Write programs that use each of the following data structures: arrays, records, strings, linked lists, stacks, queues, sets, and maps.
8.2.5: Compare the performance of alternative implementations of data structures.
8.2.6: Describe dynamic and static data structure implementations.
8.2.7: Choose the appropriate data structure for modeling a given problem.
