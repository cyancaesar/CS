# SKU 7.1

**Object-Oriented Programming, and Functional Programming**

Topics:

1. Class hierarchy and reusability of subclasses.
2. Control flow in a program using dynamic dispatch.
3. Relationship between object-oriented inheritance and subtyping.
4. Object-oriented encapsulation mechanisms.
5. Usage of iterators and other operations on aggregates, in multiple programming languages.
6. Algorithms that avoid assigning to mutable state.
7. Functions taking and returning other functions.
8. Functional approach vs. object-oriented approach.
9. Functional encapsulation mechanisms.
10. Usage of iterators and other operations on aggregates, in multiple programming languages.

SLOs:

7.1.1: Design and implement simple class hierarchy that allows reusability of subclasses.
7.1.2: Explain the relationship between object-oriented inheritance and subtyping
7.1.3: Use object-oriented encapsulation mechanisms in writing simple programs.
7.1.4: Use iterators and other operations on aggregates, in multiple programming languages.
7.1.5: Write basic algorithms that avoid assigning to mutable state.
7.1.6: Write useful functions that take and return other functions.
7.1.7: Compare functional approach with object-oriented approach.
7.1.8: Use functional encapsulation mechanisms in writing simple programs.
7.1.9: Use iterators and other operations on aggregates, in multiple programming languages.

# SKU 7.2

**Basic Type Systems**

Topics:

1. Primitive types and compound types.
2. Static type system and dynamic type system.
3. Program errors detected by a type system.
4. Program properties checked statically, and program properties checked dynamically in several languages.
5. Generics, subtyping, and overloading.

SLOs:

7.2.1: Describe primitive and a compound type.
7.2.2: Describe static type system and dynamic type system.
7.2.3: Give examples of program errors detected by a type system.
7.2.4: Identify program properties checked statically and program properties checked dynamically in several languages.
7.2.5: Write a program that does not type-check in a particular language and yet with no runtime errors.
7.2.6: Write and debug programs using types and type-error messages.
7.2.7: Write program segments that use generic types
7.2.8: Compare the following: generics, subtyping, and overloading.

# SKU 7.3

**Program Representation, Language Translation and Execution**

Topics:

1. Programs usage of other programs as their input data.
2. Abstract syntax tree.
3. Concepts of Interpreter, expression optimizer, and documentation generator.
4. Syntax and parsing vs. semantics and evaluation.
5. Low-level run-time representation of core language constructs.
6. Organization of memory into global data, text, heap, and stack sections by programming language implementations.
7. Memory leaks and dangling-pointer dereferences and their solutions.
8. Garbage collection.

SLOs:

7.3.1: Explain how programs use other programs as their input data.
7.3.2: Describe an abstract syntax tree for a small language.
7.3.3: Write a program to process some representation of code, such as an interpreter, an expression optimizer, or a documentation generator.
7.3.4: Distinguish syntax and parsing from semantics and evaluation.
7.3.5: Sketch a low-level run-time representation of core language constructs
7.3.6: Explain how programming language implementations organize memory into global data, text, heap, and stack sections.
7.3.7: Identify and fix memory leaks and dangling-pointer dereferences.
7.3.8: Discuss the concept of garbage collection.
