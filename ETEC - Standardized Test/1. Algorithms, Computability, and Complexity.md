# SKU 1.1

**Basic Analysis and Algorithmic Methods**

Topics:

1. Case behaviors of an algorithm.
2. Big O notation and complexity of algorithms.
3. Standard complexity classes.
4. Algorithms Performance
5. Greedy Algorithm.
6. Divide-and-conquer algorithm.
7. Recursive backtracking.
8. Dynamic programming.
9. Heuristic approach.

SLOs:

1.1.1. Explain case behaviors of an algorithm.
1.1.2: Use big O notation to determine the complexity of algorithms.
1.1.3: Contrast standard complexity classes.
1.1.4: Perform empirical studies to validate hypotheses about runtime.
1.1.5: Run algorithms on input of various sizes to compare performance.
1.1.6: Determine an appropriate algorithmic method (greedy, divide-and-
conquer- recursive backtracking, dynamic programming, heuristic approach) to a problem.
1.1.7: Use Appropriate algorithmic method to solve a problem.
