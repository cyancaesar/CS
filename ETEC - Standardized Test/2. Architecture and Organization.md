# SKU 2.1

**Digital Logic and Digital Systems, Representation of Data on Machine Level**

Topics:

1. The five generations of computers.
2. Multi-core architecture
3. Different representations of computer functionality, including logical expressions and gates.
4. Basic building blocks of a computer: arithmetic-logic unit, registers, central processing unit and memory.
5. CAD simulation tools for evaluating simple building blocks of a computer.
6. Behavior of a simple processor implemented at the logic circuit level.
7. Formats of numerical data from one format to another.
8. Internal representation of non-numeric data.
9. String processing.

SLOs:

2.1.1: Describe the five generations of computers.
2.1.2: Discuss multi-core architecture.
2.1.3: Describe different representations of computer functionality,
including logical expressions and gates.
2.1.4: Design the basic building blocks of a computer: arithmetic-logic
unit, registers, central processing unit and memory.
2.1.5: Use CAD tools to simulate and evaluate simple building blocks of
a computer.
2.1.6: Evaluate the behavior of a simple processor implemented at the
logic circuit level.
2.1.7: Justify the fact that in computers, everything—even instructions—
is data.
2.1.8: Convert numerical data from one format to another.
2.1.9: Explain the internal representation of non-numeric data.
2.1.10: Write simple programs at the machine level for string processing

# SKU 2.3

**Architecture of Memory System, Interfacing and Communication**

Topics:

1. Categories of memory technology.
2. Memory delay and its impact on runtime.
3. Memory management principles.
4. Functionality of systems that use virtual memory management.
5. Average memory access time under different cache and memory configurations.
6. Data transfers and I/O control implementation via interrupts.
7. Types of buses in a computer system.
8. The use of magnetic disk drive for data access.
9. Network structures like Ethernet/Bus.
10. Basics of RAID architectures.
