# SKU 6.1

**Operating System Principles**

Topics:

1. Objectives and functions of modern operating systems.
2. Client-server distributed operating systems and single user operating systems.
3. The concept of logical layer.
4. APIs and middleware.
5. Resource usage and management by application software and system software.
6. Kernel and user mode in an operating system.
7. Interrupt processing.
8. Device list and driver I/O queue.

SLOs:

6.1.1: Explain the objectives and functions of modern operating systems.
6.1.2: Discuss client-server, distributed operating systems and single user operating systems.
6.1.3: Explain the concept of a logical layer.
6.1.4: Describe the APIs and middleware.
6.1.5: Describe how an application software uses resources and how a system software manages them.
6.1.6: Contrast kernel and user mode in an operating system.
6.1.7: Explain the concept of interrupt processing.
6.1.8: Explain the use of a device list and driver I/O queue.

# SKU 6.2

**Concurrency, Scheduling, Dispatch, Memory Management and Security of OS**

Topics:

1. Concurrency within an operating system and the mechanisms to achieve it.
2. The run-time problems of the concurrent operation of many separate tasks.
3. States of a task during management of many tasks.
4. Techniques for achieving synchronization in an operating system.
5. State and transition diagrams.
6. Processes, threads, scheduling algorithms and their relationship to application domains.
7. Memory hierarchy and cost-performance trade-offs.
8. Principles of virtual memory; tasks memory-allocation; cache memory; thrashing.
9. Protection and security in an OS; features and limitations of an OS used to provide protection and security.
10. Mechanisms in an OS to control access to resources.
11. System administration tasks according to security policies.

SLOs:

6.2.1: Demonstrate the concurrent operation of many separate tasks and the run-time problems associated with it.
6.2.2: Explain the states of a task during management of many tasks.
6.2.3: Discuss techniques for achieving synchronization in an operating system.
6.2.4: Create state and transition diagrams for simple problem domains.
6.2.5: Describe processes, threads, scheduling algorithms of tasks in operating systems and their relationship to application domains.
6.2.6: Explain memory hierarchy, virtual memory, cash memory, thrashing, cost-performance trade-offs.
6.2.7: Explain various ways of allocating memory to tasks.
6.2.8: Discuss the importance, features and limitations OS used to provide protection and security.
6.2.9: Explain the mechanisms in an OS to control access to resources.
6.2.10: Perform simple system administration tasks according to a security policy.
