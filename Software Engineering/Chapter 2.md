### Software Processes

- Software process models
- Process activities
- Coping with change
- The Rational Unified Process - example of a modern software process

Software Process - A structured set of activities required to develop a software system
- Specification
- Development
- Validation
- Evolution

Software Process Model - An abstract representation of a process

Plan-driven processes - process activites are planned in advance
Agile processes - Planning is incremental

Software Process Models:
- Waterfall model - *Plan-driven model*
- Incremental development
- Reuse-oriented software engineering - Assembled from exisiting components


Waterfall model:
1. Requirement Definition
2. System Design
3. Implementation and Testing
4. System Integration and Testing
5. Operation and Maintanance

Software prototyping - An initial version of a system used to demonstrate concepts and try out design options

Benefits:
- Improved system usability
- Closed match
- Improved design quality
- Imporved maintainability
- Reduced development effort

Boehm's spiral model
- Process is represented as a spiral rather then as a sequence of activites with backtracking
- Each loop represents a phase in the process
- No fixed phases
- Risks are assessed and resolved throughout the process

Sectors of spiral model:
- Objective
- Risk assessment and reduction
- Development and validation
- Planning

Rational Unified Process - A modern generic process model that is organized into phases (inception, elaboration, construction, transition).
