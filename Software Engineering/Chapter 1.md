### Essential Attributes of Good Software

- Maintainability - capable of changing
- Dependability and Security - any system failure shouldn't affect software state
- Efficiency - software cost just not be higher than hardware cost
- Acceptability - understandable, usable and compatible with other systems


### Software engineering

An engineering discipline that is concerned with all aspects of software production from the early stage of system specification through to maintaining the system

Engineering Discipline
Using appropriate theories and methods to solve problems bearing in mind organizational and financial constraints

Software process:
- Software specification
- Software development
- Software validation
- Software evolution

General issues that affect most software:
- Heterogeneity - required to operate as distributed systems across networks
- Business and social change - software must cope with the changes
- Security and trust

Application types:
- Stand-alone applications
- Interaction transaction-based applications - web application
- Embedded control systems
- Batch processing systems
- Entertainment systems
- Systems for modeling and simulation
- Data collection systems
- Systems of systems

Software Engineering Fundamentals
A set of principles that applies to all type of software system.
- Systems should be developed using a managed and understood development process
- Dependability and performance
- Understanding and managing the software specification
- Where appropriate, you should reuse software

Key points:
- Software engineering is an engineering discipline that is concerned with all aspects of software development
- Essential software product attributes are maintainability, dependability and security, efficiency and acceptability
- High-level activites of specification, development, validation and evolution are part of all software processes
- Fundamental of software engineering are universally applicable to all types of system development
