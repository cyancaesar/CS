The aim of agile methods is to reduce the overheads in the software process and to be able to respond quickly by changing requirements.

**Agile methods principles**
- Customer involvement
- Incremental delivery
- People not process
- Embrace change
- Maintain simplicity

Plan-Driven and Agile Development:
- Plan-Driven
	- Base around separate development stages
	- Iterations occurs within activities
- Agile
	- Specification, design, implementation and testing are inter-leaved

Extreme Programming - An Agile Method
- New versions may be built *several times per day*
- Increments are delivered every *2 weeks*
- All tests must be run for every build

The Extreme Programing release cycle:
- Select user stories for this release
- Break down stories to tasks
- Plan release
- Develop/integrate/test software
- Release software
- Evaluate system

Practices:
- Incremental planning
- Small releases
- Simple design
- Test-first development
- Refactoring
- Pair programming
- Collective ownership
- Continuous integration
- Sustainable pace
- On-site customer

**Requirements Scenarios**
- User requirements are expressed as *scenarios* or *user stories*

SCRUM - a general agile method.
Focuses on managing iterative development

Three phases in SCRUM
- Initial phase
	- Outlines planning phase
	- General objectives for the project and design the software architecture
- Sprint cycles
	- Each cycle develops an increment of the system
- Project closure phase
	- Wraps up the project
	- Complete required documentation such as system help frames and user manual


**About the sprint cycles**:
- Sprints are fixed length, normally *2-4 weeks*
- Once a selection phase is done, team isolates themselves from the customer
- All communications channeled through SCRUM master
- At the end of the sprint, work done reviewed to stakeholders, the next sprint cycle then begins
